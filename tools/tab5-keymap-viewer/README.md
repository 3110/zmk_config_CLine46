# CLine46 キーマップビューワー（M5Stack Tab5）

Tab5 の 1280×720 画面に、**今のレイヤーのキーマップを実物と同じ並びで**描きます。
レイヤーを切り替えると画面全体が切り替わるので、分割キーボードの配置を覚えるのに使えます。

受信は [../CLine46Status](../CLine46Status) のライブラリが行います（AtomS3R 版と同じ状態広告）。
接続もペアリングもしないので、キーボードと PC の接続や DYA Studio には影響しません。

```
+--------------------------------------------------------------------+
| | SYMBOL   [0 BASE][1 SYMBOL][2 MOUSE][3 SCROLL]  BT0 macOS L R  * |
|   左手                                右手                         |
|  [ ^ ][ = ][ 7 ][ 8 ][ 9 ][ @ ]       [ ( ][ " ][ ) ][ ; ][ ! ][ ? ] |
|  [ - ][ + ][ 4 ][ 5 ][ 6 ][ # ]       [ [ ][ ' ][ ] ][ : ][ & ][ | ] |
|  [ / ][ * ][ 1 ][ 2 ][ 3 ][ _ ]       [ / ][ \ ][ , ][ . ][ $ ][ % ] |
|       [Esc][ 0 ][ . ][ ▽ ][Spc][ ▽ ]  [Ent][BS ]  ( )  [Del][ ▽ ]    |
| +- このレイヤー ------------------+ +- 受信 -----------------------+ |
| | Space を押している間だけ有効 ... | | 受信中 123件 / 間隔 1002ms   | |
| +--------------------------------+ +------------------------------+ |
+--------------------------------------------------------------------+
```

| 表示 | 意味 |
|---|---|
| 色の付いたキー | そのレイヤーを有効にしているキー（押下中） |
| 暗いキーと右上の `▽` | そのレイヤーでは割り当てが無く（`&trans`）、下のレイヤーのキーが効く |
| キーの下の小さい文字 | 長押ししたときの動作（`MOUSE` / `SYMBOL` など） |
| 右下の丸 | トラックボール。SCROLL レイヤーでは色が付き `SCROLL` になる |
| ヘッダ右端の点 | 広告を受けた直後に明るくなる。橙なら受信できていない |
| 「受信」欄の間隔 | 広告を受けた間隔。今のファームは操作中 約1000ms、アイドル中 約10000ms |

ヘッダのレイヤー名（`0 BASE` など）を**タッチすると、そのレイヤーを4秒間表示**します。
キーボードに触らずに配置を確かめたいとき用です。

## 今の制限

- **レイヤーの切り替わりは最大1秒ほど遅れて映ります。** キーボードが広告を出すのが
  操作中1秒ごとのためです。変化した直後だけ間隔を詰めるファームの改修で縮める予定です
- **表示しているのはレイヤー番号から引いたキーマップです。** キーの割り当ては
  [src/keymap.h](src/keymap.h) に `config/CLine46.keymap` の工場出荷値を写してあります。
  DYA Studio でキーマップを変えた場合は、この表も直してください
- 押したキーを光らせる機能はまだありません（広告に押下状態が載っていないため）
- 凡例は keymap-drawer と同じく US 配列の意味です。OS を JIS 配列で使っていると、
  一部の記号は実際の出力と表示が食い違います

## ビルドと書き込み

```sh
git submodule update --init tools/config
cd tools/tab5-keymap-viewer
pio run -e m5stack-tab5 -t upload -t monitor
```

シリアルモニタには広告を受けるたびに1行出ます。まずここで受信できているかを確かめてください。

```
L1:SYMB  右 1284mV/72%  左 1270mV/68%  -B--L-  OS:macOS(既定-)  prof:0接続  稼働42min  前回:電源投入  RSSI:-58dBm  ID:3A
```

## うまくいかないとき

| 症状 | 確かめること |
|---|---|
| 「キーボードを探しています」のまま | キーボードの状態広告がオンか（SCROLL + 右手上段 `I`）。同じ広告を AtomS3R で受けられるか |
| シリアルに「BLE のスキャンを始められませんでした」 | Tab5 の BLE は無線用の ESP32-C6 側で動き、P4 からは ESP-Hosted 経由で使います。起動時にシリアルへ出る `ESP-Hosted:` の行で両側の版を確認してください。`（C6 側に更新あり）` と出たら C6 側のファームが古く、BLE が使えないことがあります（arduino-esp32 の `ESP_HostedOTA` のスケッチ例で更新できます） |
| 画面が縦長・上下逆 | [src/main.cpp](src/main.cpp) の `SCREEN_ROTATION` を 1 か 3 に変える |
