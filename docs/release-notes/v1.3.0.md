[v1.2.0](https://github.com/3110/zmk_config_CLine46/releases/tag/v1.2.0) からの更新です。
**状態を流す BLE 広告をキーでオン/オフできるようにした**のが主な変更で、
キーマップの打鍵内容は変わっていません(SCROLL レイヤーに1キー追加のみ)。

## 変更点

### 広告をキーで止められるようにした(`&status_adv`)

受信側(M5Stack)を使っていないときは広告を出す意味がないので、キーから止められます。

```dts
&status_adv SADV_TOG   // 押すたびに反転
&status_adv SADV_ON    // 出す
&status_adv SADV_OFF   // 止める
```

- **SCROLL レイヤーの右手上段(RESET の隣)** に `&status_adv SADV_TOG` を置きました
- DYA Studio のキーマップエディタにも **Status Broadcast** として出るので、好きなキーに移せます
- locality は既定の `BEHAVIOR_LOCALITY_CENTRAL` なので、**左手のキーに割り当てても動きます**
- 切り替えた状態は settings に保存され、**次の起動でも引き継ぎます**
  (`CONFIG_CLINE46_STATUS_ADV_PERSIST`、既定 y)

非接続の広告には「誰かが受信しているか」を知る手段がありません(受信側はスキャンする
だけで、こちらには何も返しません)。そのため自動でのオン/オフは作れず、明示的な
切り替えにしてあります。

なお**消費電流の差はごくわずか**です(1秒間隔・24バイトの非接続広告)。止める主な理由は
電池ではなく、**使わないときに平文の広告を出しっぱなしにしないこと**だと考えてください。

### 止める前に「お別れ」パケットを流すようにした

いきなり黙ると、受信側は沈黙のタイムアウト(操作中約15秒 / アイドル中最大45秒)が
過ぎるまで「圏外なのか、止められたのか」を区別できません。そこで停止の直前に
`CLINE46_STATUS_FLAG_ADV_STOPPING`(`flags` の **bit6**)を立てたパケットを
200ms 間隔で `CONFIG_CLINE46_STATUS_ADV_FAREWELL_MS`(既定1000ms)のあいだ流してから
止めます。5回ほど出るので、1〜2回取りこぼしても届きます。

**バイト配置は変えていないので形式 version は 2 のまま**です。古い受信側はこのビットを
無視するだけで、そのまま動きます。

### 受信側の待ち受け画面を作り直した

`NO SIGNAL` の一枚板をやめて、理由で2種類に分けました。

| 画面 | 見た目 | いつ出るか |
|---|---|---|
| `SEARCHING` | 中心から青い波紋が広がる(1.8秒周期) | 圏外・電池切れ・電源オフなど、**理由が分からない**とき |
| `OFF` | 橙の電源マークがゆっくり明滅(3秒周期) | `&status_adv` で**意図的に止めた**とき |

`OFF` 側はお別れパケットで判定するので、**待ち時間ゼロ**で切り替わります。

ライブラリ(`tools/CLine46Status/`)には `broadcastOff()` を追加しました。`alive()` は
このとき即 `false` を返すので、**自作のスケッチでも待ち時間なしで**「受信なし」に落ちます。

## 書き込みと、アップグレード時の注意

> **右手と M5Stack を更新してください。左手は焼き直し不要です。**
> 左手は devicetree にビヘイビアのノードが増えるだけで、動作は v1.2.0 と同一です
> (ドライバは Central だけでビルドされ、キーマップを処理するのも Central だけです)。

- キーマップは SCROLL レイヤーに1キー増えただけです。Studio で編集している場合は、
  そちらの内容が優先されるので、必要なら Studio から `Status Broadcast` を割り当ててください
- M5Stack 側は `tools/CLine46Status/` と `tools/atoms3r-status-display/` の両方が
  更新されています。`git pull` のあと `pio run -e m5stack-atoms3r -t upload` し直してください
- 保存は `CONFIG_ZMK_SETTINGS_SAVE_DEBOUNCE`(このリポジトリでは**10秒**)だけ遅らせて
  まとめます。**切り替えてから10秒以内に電源を切ると保存前の状態に戻ります**
- 受信側を自作している場合、`flags` の bit6 が増えています。使わなければ無視して構いません
