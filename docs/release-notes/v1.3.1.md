## 変更点

### README を「使う人向け」に書き直した

これまでの README は、キーポジション番号や west の設定、元リポジトリとの差分まで
1枚に詰め込んでいて、**初めて使う人が最初に読むもの**にはなっていませんでした。
できること → 必要なもの → 導入 → 使い方 → 困ったときは、の並びに組み直して、
実装やビルドの詳細は `docs/` に移しました。

| 置き場所 | 内容 |
|---|---|
| `README.md` | できること、導入手順、日々の使い方 |
| [`docs/build.md`](https://github.com/3110/zmk_config_CLine46/blob/v1.3.1/docs/build.md) | ブランチ運用、GitHub Actions とローカルでのビルド、書き込み、**リリース手順** |
| [`docs/dya-studio.md`](https://github.com/3110/zmk_config_CLine46/blob/v1.3.1/docs/dya-studio.md) | DYA Studio の各タブでできること、保存の考え方、トラックボールの設定 |
| [`docs/internals.md`](https://github.com/3110/zmk_config_CLine46/blob/v1.3.1/docs/internals.md) | ファイル構成、キーポジション番号、west の構成、元リポジトリとの違い |
| [`docs/known-issues.md`](https://github.com/3110/zmk_config_CLine46/blob/v1.3.1/docs/known-issues.md) | 既知の事項と回避策 |
| [`docs/status-advertisement.md`](https://github.com/3110/zmk_config_CLine46/blob/v1.3.1/docs/status-advertisement.md) | BLE 広告で流している内容の仕様 |

あわせて、README と `tools/atoms3r-status-display/README.md` の**アスキーアートを
半角文字で描き直しました**。罫線素片と全角文字を混ぜていたため、等幅フォントでも
環境によって枠がずれていました。効いていなかった強調記法も直しています。

### Release ワークフローを `main` 限定にした

`workflow_dispatch` は実行するブランチを選べるので、`develop` や作業ブランチを
選んだままでも動いてしまい、**そちらのコミットにタグが付く**状態でした。
入力の確認の時点で `main` 以外を弾くようにしています。

### ビルドの二重実行をやめた

`on: [push, pull_request, ...]` だったため、PR を出しているブランチに push すると
**同じコミットを push 側と PR 側で2回ビルド**していました。push で走るのを
`main` / `develop` に絞り、PR とワークフローの手動実行はこれまでどおりにしています。
作業ブランチを push しただけではビルドは走りません（PR の前に試したいときは
Actions → **Build** → **Run workflow**）。

## ブランチ運用

このバージョンから、既定ブランチは `develop` です。

```
feature/xxx ──PR──> develop ──PR(merge commit)──> main ──タグ/リリース
                       ^                            |
                       └──────── 戻しマージ ─────────┘
```

詳しくは [`docs/build.md`](https://github.com/3110/zmk_config_CLine46/blob/v1.3.1/docs/build.md) を見てください。
