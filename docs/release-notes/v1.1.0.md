[v1.0.1](https://github.com/3110/zmk_config_CLine46/releases/tag/v1.0.1) からの更新です。**DYA Studio `v2026.09.20.0` への追随**と、**PMW3610 ドライバの差し替え**が中心で、キーマップは変わっていません。

## 変更点

### PMW3610 ドライバを cormoran 版に差し替えた

[badjeff/zmk-pmw3610-driver](https://github.com/badjeff/zmk-pmw3610-driver) から
[cormoran/zmk-driver-pmw3610-with-custom-studio-rpc](https://github.com/cormoran/zmk-driver-pmw3610-with-custom-studio-rpc) へ。
Studio RPC 付きなので、**センサー自体の設定を焼き直さずに変えられる**ようになりました。

| 変えられるもの | 場所 |
|---|---|
| CPI(200〜3200、200 刻み)、X/Y 反転、XY 入れ替え、スマートアルゴリズム、常時稼働、ダウンシフト/サンプル時間、最小レポート間隔 | Trackball タブの **PMW3610 Drivers** |
| センサーの生画像(22×22)、製品 ID・リビジョン・SQUAL などの診断値 | Troubleshooting タブ |

- `compatible` は `pixart,pmw3610-alt` → `cormoran,pmw3610`。DT のプロパティ(`irq-gpios` / `cpi` / `evt-type` / `x-input-code` / `y-input-code`)は同じです
- Kconfig は `CONFIG_PMW3610_ALT_*` → `CONFIG_PMW3610_*` に改名。`.conf` の値は**工場出荷値**の扱いで、Studio で保存した値が起動時にその上に乗ります
- `settings-id = "ball"` を付けたので、保存キーは `<項目>@ball` になり、画面上でもセンサー名が読めます
- このサブシステムは**ロック対象**です。読むだけの操作でも `&studio_unlock`(SCROLL + 位置42)が要ります

### DYA Studio `v2026.09.20.0` に追随した

アプリ側の新機能(デスクトップアプリ、キー編集のフローティングウィンドウ、WebMCP、スマホ UI、簡体字中国語)は
**プロトコルが変わっていないため、ファームの変更なしでそのまま使えます**。
ファーム側で追随したのは `zmk-module-runtime-input-processor` で、タグ `zmk-v0.4.0.0` から `main` に上げました。
入力プロセッサ設定の保存先が [zmk-feature-custom-settings](https://github.com/cormoran/zmk-feature-custom-settings) になり、
Settings タブの詳細設定にも `cormoran_rip` として出てきます。

### README を更新した

- 「新バージョンで増えたこと」「トラックボールのセンサー設定(PMW3610 ドライバ)」の節を追加
- 「採用を検討できるもの(未採用)」に `zmk-module-devtool` と `zmk-feature-zephyr-setting-expose` を記載

## 書き込みと、アップグレード時の注意

> **トラックボールの保存済み設定(感度・回転など)は初期化されます。**
> 入力プロセッサの保存形式が変わったためで、旧形式からの移行はモジュール側が行いません。
> Studio で設定し直してください。

- **右手(`CLine46_R.uf2`)を焼き直してください。** 左手はサイズも構成も v1.0.1 から変わっていないので、焼き直さなくても動きます
- キーマップは v1.0.1 から変わっていないので、Studio で編集していない限り「Restore Stock Settings」は不要です
- 焼いたあとは `&studio_unlock` してから Trackball タブを開くと **PMW3610 Drivers** の欄が出ます
